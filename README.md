## Background
This project was created following a implementation guide that was collaged using AI and inspiried by multiple different sources and learning materials. The point is to maximize learning using LLMs while still figuring out, understanding and developing code and infrastructure by yourself. While the guide is not perfect, it sufficiently simulate the learning style universities like to adopt. The idea originated from a Canonical Technical Interview, where the author had a interview to prepare for, but wanted to make a project that emphasized learning and had value for their Portfolio.

See 'mysh-implementation-guide.pdf'.
